# PCCS 宽屏分层模板 v3

## 模板选择和保存内容

用户指定的最新 PPTX 优先；未指定时用 `assets/pccs-wide-v3.pptx`。旧版 `assets/pccsworship.pptx` 仅在明确选择 legacy 时使用。所有路径相对当前技能目录。

另外提供可直接使用的 `assets/pccs-wide-v3-foreground.pptx`：单页、无上部背景图片、无历史歌词和版权，Logo及中英文名称完整保留，正文/歌名/同传字段可编辑，字幕紫色云雾默认显示，65%透明备选云雾默认隐藏。插入自己的图片时，将图片放到前景之下。

完整版参考资产保留本次定稿的 64 页，作为可复制的样式和布局参考，并非没有文字的空白模板。新建周次时只复制需要的代表页，替换歌词、歌名、经文和版权信息，删除未使用的历史页面；不要沿用 0920 的内容或 64 页这个数量。背景专项修订则保留用户源文件全部页数、顺序和文字。

代表页：1 歌名＋两行歌词，2 续页，9 三行歌词，16 诗篇90，17 诗篇93，18 第二首歌首段，44 第三首歌首段。1–15、18–43、44–64 分别使用三个歌曲场景，16、17 为独立经文场景。页码只用于检索本资产。

`assets/pccs-wide-v3/manifest.json` 记录资产哈希、实际图层位置与原始形状名称。`assets/pccs-wide-v3/layers/` 保存从成品直接提取的透明 PNG 原件，包括完整 Logo、字幕云雾与底部装饰，不含文字截图。`references/background-prompts-v3.md` 保存五幅背景的完整提示词。预览在 `assets/pccs-wide-v3/preview.png`。

## 尺寸与字形

| 项目 | 当前宽屏 v3 | legacy |
|---|---|---|
| 画布 | 960×540pt，即13⅓×7.5英寸，16:9 | 720×405pt |
| 背景 | 原生16:9，铺满0,0,960,540pt | 1920×920，放在0,0,720,345pt |
| 歌名 | KaiTi 40pt | KaiTi 54pt |
| 歌词 | KaiTi 52pt，固定字号 | KaiTi 48pt |
| 经文 | SimSun，当前样页38pt，按容量选最大可读字号 | KaiTi，通常48pt |
| 右下歌名 | KaiTi 22pt | 按旧模板 |
| 同传 | 两行英文，28pt为测试起点 | 按项目要求 |

16:9 是比例，字号是物理点值。同为16:9，画布由720放大到960后，保持字体点值会让字相对屏幕变小。迁移时先用 `新字号=旧字号×新画布宽/旧画布宽` 保持比例，再整体调节层级；本次定稿的40/52是视觉调整后的值，不是机械换算结果。不要把这些值强加到另一份用户模板。

主内容留在上部。歌词参考框 `x64,y105,w832,h250pt`，每页最多三行，优先完整乐句与两行布局，关闭自动缩小。歌名参考框 `64,30,832,54pt`；短金色细线位于 `432,92,96,0.7pt`。两行首段在标题下顶端对齐，连续页使用稳定锚点。

歌词使用深灰紫 #302733，轻微贴近字形的字体阴影增加立体感。继承资产中的阴影参数；不要加外发光、模糊重影或用复制文字模拟阴影。需重设时从约1pt位移、1–2pt模糊、55–70%透明度试起，按实际投影大小检查边缘清晰度。

经文合并仅在用户要求时进行。优先一页；用户允许时，可在字号明显影响观看前拆为两页。38pt是样页结果，不是所有经文的最低或固定字号。保留精确文字、经节顺序和用户固定的行界；不要将全局的“最多三行歌词”施加给经文。

## 背景制作：上部浅色、右侧中部景物、下部自然灰紫

每首歌曲和每组经文按内容设计场景，同一组重复页复用场景。共同色系为乳白、珍珠白、极浅淡紫、石灰岩灰和克制的暖金。上半部尽量接近乳白色、低对比，左侧和中心阅读区继续保持清净；主要山体、瀑布、树木等可放在右侧中部，避开实际最长文字。

下方四分之一保留自然水面、山坡或谷地等简单纹理，接近低饱和灰紫。它是景物的一部分：不能画成紫色纯色块、底栏、色带、横向硬渐变或空白补丁。控制复杂色彩、硬地平线和高光。自然纹理应能与独立字幕云雾融合，但不要在背景里再画一团字幕烟雾，更不要整页铺雾。

全新重绘使用完整文字提示词，不传入旧图或参考图片。保留生成的原始文件；不要靠后期涂紫、加白块、裁剪或拼接来“修好”不合格构图。生成工具未返回精确1920×1080时，原生比例接近16:9的尺寸可直接使用并记录，例如1672×941；不要声称图片是不存在的分辨率。把独立生成图片放在最底层，可用唯一背景媒体替换而保留布局和对象身份。

先检查背景实际存放处。有些周次的整幅背景是 `CustomLayout.Shapes` 中的图片，而不是幻灯片的 `Background.Fill`；仅设置 `Slide.Background.Fill.UserPicture` 不会替换可见画面。为每个新场景复制相应版式，在副本中替换那张背景图片，赋予唯一 `Name` 和 `MatchingName`，再把需要该场景的页面指向该版式。Logo、教会名称、底部装饰和字幕云雾留在既有前景层；同一场景的重复页共用一份版式，避免无谓膨胀。

## 固定前景、Logo、教会名称

从下到上保持可独立编辑：背景 → 可选局部字幕云雾 → 固定底部装饰与教会标识 → 文字。具体交叠以源模板的对象顺序为准，字幕不能被前景盖住。

低底栏为 #E7DFED 及柔和透明过渡，不提高成大面积紫色区域，不增加台阶、明显分界线、突兀的左右紫块。纯色底栏属于独立模板前景，禁止纯色的要求针对生成背景图。替换整张背景时，前景、Logo和名称保持原位。

使用完整的大写 PCCS Logo 原件，保留金色主体、竖柱底部结构、底部柔影和顶端较透明的暖色光晕。顶端是光芒效果，不另外画星形图标。不要臆造结构的神学含义，也不要在普通换背景任务中重画、裁掉光晕或增添光影。当前独立完整Logo参考位置为 `4.5,475.75,94.114,59.5pt`，已包含尖端，不需再补旧版 tip overlay。

中文和英文名称各自单行，紧凑排在Logo右侧的左下角，视觉对齐，保留字幕宽度。当前中文 Noto Serif SC 18pt加粗，英文 Garamond 11.5pt加粗；这是教会标识的字体，不能被“所有中文用KaiTi”覆盖。中文框参考 `104,494,174,23pt`，英文框见manifest。不要加图标、点缀或刻意拉长名称区。只移动Logo时，不更改其图形；仅换背景时，不改名称字号与对齐。

## 字幕云雾与透明模板

仅在字幕显示位置叠加局部云雾。当前可见云雾为独立RGBA图，框约 `0,374.3,960,119.467pt`；另有65%透明备选默认隐藏；其原始PNG保存为 `subtitle-mist-optional-base.png`，需要额外应用原PPT的 `alphaModFix=35000`，即图片透明度65%，才能复现效果。该PNG本身不是65%透明成品。同传框约 `120,420.35,720,69.767pt`，居中两行英文。原空框继承字号约29.33pt，形状名称的28pt并不等于实际字号；双行测试明确设为28pt，今后按实际文字和投影检查选择。避免侵入左下标识和右下歌名、版权。

新模板默认显示当前版本的字幕紫色云雾，即使字幕尚未输入也保持开启；65%透明备选层默认隐藏，避免重复叠加。用户可以按需手动隐藏云雾。更新其他现有PPT时按该次请求处理显隐；仅换背景且未要求修改显隐时保留源文件设置。背景须在关闭云雾时也完整、美观；开启后不得出现硬边或污浊色团。只启用一个所需云雾层，不叠多档透明度。

“透明度30%”指峰值不透明度约70%，不是不透明度30%；还要保留软边的渐变alpha。嵌入PNG的现有alpha与PowerPoint图片透明度会相乘，不要重复施加透明度。当前PNG的alpha范围为0–178，强度已经写入alpha；备选原始PNG的alpha范围为0–254，由PPT额外乘0.35。用manifest记录的图像alpha与PPT效果共同复现，不从文件名推断。新增档位需要从确认的原始alpha定义生成，并注明透明/不透明，不能仅改文件名。

PowerPoint 365可通过“开始 → 选择 → 选择窗格”，或“形状格式/图片格式 → 选择窗格”切换相应对象眼睛图标；不要把Alt+F10作为唯一途径。对象可能位于幻灯片、组或版式，先定位后操作。空的命名字幕文本框是保留接口，不是待清理的无用占位符。

需要无上部背景的模板时，优先复制 `assets/pccs-wide-v3-foreground.pptx`。若用户另有新版模板，则复制该参考页，清理示例内容，在副本版式中移除背景图片，保留透明前景、完整Logo、可编辑教会名称和独立云雾层。PPT画布本身不是透明PNG；提供透明叠加素材时使用RGBA前景资产，底部原生渐变仍需保持可编辑。不要把整页截图当作透明模板。

## 专项背景修订与验证

用户上传的文件是实际编辑基线，不能退回工作区的更早版。背景专项任务无需重新查歌词来源或重新分页；从源文件提取并保存精确文字和页序用于比对。只替换确认的背景媒体，保留其他package部分，记录替换清单和原文件SHA256。五幅图只是本次资产数量，后续按实际场景数量处理。

渲染全部受影响页面，逐张检查最长行、三行歌词和最密经文；不能仅看缩略拼图。重复页可在确认逐像素一致后复用视觉判断。每个独立版式完成复制、改字、保存、关闭、重开测试，检查背景、Logo、底栏、字幕云雾显隐和文字可编辑性。额外检查云雾关闭、开启及两行同传叠加；测试字幕放在QA副本，未要求时不写入正式歌词。背景专项修订还须验证非背景内容没有变化。

无上部背景的宽屏模板用服务技能的 `qa_pccs_service_pptx.ps1 -Profile wide-v3 -NoUpperBackground` 检查，允许背景数为0，仍验证前景、Logo、云雾和复制稳定性。该开关只用于明确无背景的模板，普通成品仍要求每个场景有背景。
