# 离线伴奏、同步歌词与祷告

需要在歌词页里自动播放指定录音、在祷告时停住、下一页接唱时使用。本流程保留固定音乐切点，适合可按录音时刻换页的场景。普通现场敬拜仍按用户流程选用手动翻页。

1. 锁定用户指定版本、时长、编排与可使用的音乐来源。优先使用本地授权音频。指定线上版本时核对标题、演唱或伴奏者、音轨、段落、歌词提示画面和出处，再取得可嵌入音频。只在本周项目中保存录音。
2. 按录音实际段落标歌词提示点。在完整乐句或段落后选择祷告切点。使用 FFmpeg 或本地音频工具将原曲分为切点前、后两个 MP3，不留重叠或遗漏，保留音乐本身的重复和尾音。若录音剪裁了首尾静音，记录剪裁和切点。用节拍与试听确定切点，不沿用历史时间。
3. 祷告前第一张歌词页自动播放前段，跨本段歌词页直到结尾。祷告页无媒体和计时，显示至操作者手动前进一次。随后第一张歌词页自动接后段，从切点继续。关闭音轨和放映循环。通常让最后一页停留，伴奏自然结束。
4. 若使用 720 pt [周次模板](../../pccs-service-pptx/references/weekly-production.md)，在生成计划的顶层加入 `audio_cues`，如：

```json
{
  "audio_cues": [
    {"start_slide": 1, "mp3": "before-prayer.mp3", "advance_seconds": [10.4, 8.2]},
    {"start_slide": 4, "mp3": "after-prayer.mp3", "advance_seconds": [7.1, null]}
  ]
}
```

数组长度是伴奏跨过的连续页数。这里第 3 页另用 `prayer` 原型，不列入任一段。秒数按相邻提示点相减计算；祷告前最后一页留出足够播放末音和媒体初始化的时间。`null` 表示该页由操作者前进或停留，适合最后一页。各个范围按最终成品从 1 开始计算。

原生 PowerPoint 也可手工配置。分别嵌入两段音频，设置随页开始、跨本段页面、隐藏媒体图标。检查动画窗格中的媒体播放效应为「与上一动画同时／自动」；仅设置老式 `PlayOnEntry` 不足以证明媒体时间线会实际自动触发。然后设置歌词定时切换，祷告页手动切换。

交付前在桌面 PowerPoint 放映整首。核对两段自动起播，祷告前、中、后的真实输出，祷告页停留后按一次前进，末尾静音并只播放一遍。内嵌文件和静态画面检查不能替代实际放映。源录像内部正常的主副歌重复继续照录。需要 PDF 时从相同 PPTX 导出静态页面。
